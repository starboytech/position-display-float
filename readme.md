## Git Commands

1. `git config --global --list` shows your git configuration. we're looking for email and name.
2. `git config --global user.email "youremailgoeshere"` to set your email
   `git config --global user.name "your name goes here"` to set your name
3. `git init` initializes empty repository
   `git status` shows the status of the repository
   `git add .` adds all files in the folder to be tracked (you can also defined specific files)
   `git commit -m "your commit msg here"` creates a commit
   `git log` to see all commit history
4. git checkout <yourbranchorcommithashhere></yourbranchorcommithashhere> switches between branches/commits
   git branch tells you which branch you have and you're on (\*)
